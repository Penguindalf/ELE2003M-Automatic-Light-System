# ELE2003M-Automatic-Light-System
Arduino-based automatic lighting circuit using an LDR and potentiometer. An I2C LCD displays the ambient light level and threshold as percentages. The LED activates automatically when the ambient light drops below the set threshold. Built for the University of Lincoln BEng Electrical and Electronic Engineering programme.
The source code was version controlled using GitHub. A separate improvement branch was created to implement the constrain() function, allowing the original and improved versions to be compared directly.
